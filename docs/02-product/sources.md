# Sourced References & Data Index

This document records all verified external statistics and data citations used in NarraTV documentation, Devpost submission materials, and product briefs. Only claims verified from live opened sources are included.

## 1. Global Vision Impairment Statistics
* **Source**: World Health Organization (WHO) — *Blindness and visual impairment* Fact Sheet
* **URL**: https://www.who.int/news-room/fact-sheets/detail/blindness-and-visual-impairment
* **Date Verified**: 2026-09-02
* **Verified Claim**: Globally, at least **2.2 billion people** have a near or distance vision impairment. In at least 1 billion of these cases, vision impairment could have been prevented or is yet to be addressed.
* **Usage**: Cited in `README.md`, `product-brief.md`, and `devpost-copy.md`.

## 2. Audio Description Tracking & Industry Availability
* **Source**: American Council of the Blind (ACB) — *Audio Description Project (ADP)*
* **URL**: https://adp.acb.org/
* **Date Verified**: 2026-09-02
* **Verified Fact**: ACB's Audio Description Project maintains the international directory of described commercial titles, tracking the ongoing gap between broadcast captioning (subtitles) and audio description availability across streaming catalogs.

---

## 3. Broadcast Access Services & Quota Frameworks
* **Source**: UK Office of Communications (Ofcom) — *Television Access Services*
* **URL**: https://www.ofcom.org.uk/
* **Date Verified**: 2026-09-02
* **Verified Fact**: Standard broadcast regulations enforce audio description minimums (typically 10% on major linear channels), while independent web streaming, non-broadcast VoD, and emerging video catalogs carry no universal audio description mandate.
